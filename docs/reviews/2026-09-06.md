### #1 `lib/netomox/pseudo_dsl/p_node.rb:23` — クラッシュ【未対応】

**重大度:** CONFIRMED (確認済み)

**概要:** `Enumerable#grep` がパターン引数なしで呼ばれており、実行時に `ArgumentError` が発生する

**詳細:**
`.filter { |name| name =~ /p\d+/ }` を `.grep { |name| name =~ /p\d+/ }` に変更した際、
`Enumerable#grep` に必須の第1引数 (パターン) を渡していない。
`grep` にブロックのみを渡すのは無効な呼び出し。
`PNode#auto_tp_name` を呼ぶたびに `ArgumentError: wrong number of arguments (given 0, expected 1)` でクラッシュする。

**修正案:** `.grep(/p\d+/)` に変更するか、`.filter { |name| name =~ /p\d+/ }` に戻す

### #2 `lib/netomox/topology/network.rb:176` — データ破壊【未対応】

**重大度:** CONFIRMED (確認済み)

**概要:** `Network#clear_diff_state` がソーストポロジからノード・リンクを物理削除してしまう

**詳細:**
`@nodes.delete_if { |n| n.diff_state.detect == :deleted }` が、
`diffable_forward.rb:132` の `set_diff_state(lhs, forward: :deleted)` で `:deleted` に
マークされた lhs の実ノードオブジェクトを削除する。

- 1回目の `nw_a.diff(nw_b)` 実行: `nw_b` に存在しないノードが `nw_a` のノードオブジェクト上で `:deleted` とマークされる
- 2回目の `nw_a.diff(nw_c)` 実行: `clear_diff_state` が上記ノードを `nw_a` から物理削除する
- 結果: 2回目以降の diff でソーストポロジが縮小しており、本来検出すべき差分が欠落する

### #3 `lib/netomox/topology/node.rb:83` — データ破壊【未対応】

**重大度:** CONFIRMED (確認済み)

**概要:** `Node#clear_diff_state` が termination-point をソースノードから物理削除してしまう

**詳細:** #2 と同じパターン。`@termination_points.delete_if { |tp| tp.diff_state.detect == :deleted }` が
ソースノードの TP を永続的に削除する。繰り返し `diff()` を呼ぶと TP リストが縮小し続ける。

### #4 `lib/netomox/topology/network.rb:179` — ステート汚染【未対応】

**重大度:** PLAUSIBLE (蓋然性あり)

**概要:** `Node#clear_diff_state` がノード自身の `@diff_state` をリセットしない

**詳細:**
`clear_diff_state` は配下の TP の diff 状態をリセットするが、ノード自身の `@diff_state` を
`DiffState.new` に戻さない。次の `diff()` 呼び出し時に `select_diff_state` が古い
`forward` 値を読む可能性がある。
`diffable_forward.rb:43` の `lhs.diff(od)` 再帰呼び出しで、lhs のノードが古い forward 状態を
持ったまま `select_diff_state` に渡る場合がある。
